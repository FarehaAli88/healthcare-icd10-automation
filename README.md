# Automated ICD-10 Coding Assistant

### Overview
This project addresses the critical challenge of manual medical coding by leveraging the OpenAI API to automate the extraction of diagnostic information from patient transcripts. The solution maps unstructured clinical narratives to standardized ICD-10 billing and diagnostic codes, improving administrative efficiency and accuracy in healthcare documentation.

### Technical Stack
* **Language:** Python
* **Core Technologies:** OpenAI API, NLP (Natural Language Processing)
* **Methodology:** Automated entity extraction, data mapping, and schema alignment.

### Key Outcomes
* **Efficiency:** Automated a historically manual, time-intensive documentation process.
* **Accuracy:** Reduced the margin for human error in diagnostic categorization and medical billing.
* **Scalability:** Developed a modular architecture capable of being integrated into existing Electronic Health Record (EHR) systems.

### Why This Matters
As a founder in the situational intelligence space, I believe AI's most profound impact will be in highly regulated, high-stakes environments like healthcare. This project demonstrates how we can use LLMs to automate complex administrative workflows while maintaining the precision required for patient care.
